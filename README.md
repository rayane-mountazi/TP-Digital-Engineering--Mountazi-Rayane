## Bilan des commandes Git

### `git status`

Permet de vérifier l'état du dépôt, les fichiers modifiés, les fichiers en attente d'ajout et ceux prêts pour un commit.

### `git remote -v`

Permet d'afficher les dépôts distants configurés ainsi que leurs adresses utilisées pour récupérer et publier les modifications.

### `git log --oneline --graph --all`

Permet de visualiser l'historique des commits sous forme de graphe, en affichant les différentes branches et leurs fusions.
