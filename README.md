## Bilan des commandes Git

### git status

Permet de vérifier l'état du dépôt, les fichiers modifiés et les fichiers prêts pour un commit.

### git remote -v

Permet d'afficher les dépôts distants configurés et leurs adresses pour récupérer ou publier les modifications.

### git log --oneline --graph --all

Permet de visualiser l'historique des commits sous forme de graphe, avec les branches et les fusions.
